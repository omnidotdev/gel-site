# 🧊 gel Site

Marketing website for [gel](https://github.com/omnidotdev/gel), declarative whole-system management for Arch Linux in typed Rust config.

## Local Development

Install dependencies:

```sh
bun i
```

Run dev server:

```sh
bun dev
```
